# Aria

An Android music client that combines YouTube Music playback with Spotify-driven discovery. GPL-3.0-only.

Aria is an independent project. It is **not affiliated with, endorsed by, or sponsored by** Google, YouTube, YouTube Music, Spotify, or any other service it connects to. All trademarks belong to their owners.

Status: walking skeleton. The module layout, Room v1, a signed-registry verifier, the glass UI primitives, a minimal playback service, and a search-and-play screen backed by YouTube Music (through InnerTubeX) exist. Spotify, downloads, the full player UI, and PoToken generation do not. The name `Aria` and the package ID `app.aria.music` are placeholders (see [docs/release-gates.md](docs/release-gates.md)).

Source: https://github.com/iamutsavrajoria/Aria-Music
